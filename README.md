# Painel da votação do PLP 299/2026

Site estático em HTML, CSS e JavaScript puro. O gráfico usa Apache ECharts via CDN.

## Executar localmente

Na pasta do projeto:

```bash
python3 -m http.server 4173 --directory dist
```

Depois, abra `http://localhost:4173` no navegador.

## Fonte dos dados

Relatório de votação aberta do Senado Federal, Requerimento nº 770/2026, emitido em 12/11/2026 às 18:26:29.
